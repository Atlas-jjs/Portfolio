Overview

AWS Community Day Philippines 2026 is a premier, community-led cloud conference organized by the AWS User Group Philippines that unites developers, cloud architects, and technology enthusiasts. The event focuses entirely on hands-on learning and practical cloud engineering across fields like AI, DevOps, security, and serverless architecture.

It serves as a collaborative educational hub where attendees can share actionable insights, develop applied skills, and network with industry peers to tackle real-world challenges.
